# specialize

The specialize configuration pass of Windows Setup is used to custome a generalize created Windows Reference image to specialize the generalize'd Windows Reference image for departments or individuals in an organization.

This is where machine specific settings are processed, like domain information, wifi, network, international settings, department webpages, website restrictions, departmental network printers and other devices. It runs on the next reboot after the generalize pass.

This section is beyond the scope of this repo which is aimed for individual pc's and small businesses.

However, for more information visit the links below.
