# specialize

The specialize configuration pass of Windows Setup is used to custome a generalize created Windows Reference image to specialise the generalize Windows Reference image for departments or individuals in an organization.

This section is beyond the scope of this repo which is aimed for individual pc's and small businesses.

However, for more information visit the links below.
